5. ## Answers

1. Zero-shot was good enough for summarising customer messages because it provided simple and clear summaries without requiring examples.

2. Few-shot improved the messages where AI misunderstood the company's rules. The exact corrected message IDs will depend on my test results.

3. Few-shot can improve Hinglish and tricky messages because examples demonstrate the expected language, category, priority and reply format.

4. I would recommend few-shot prompting for daily customer-support classification because it provides examples of company-specific rules. However, high-priority fraud complaints should always be checked by a human.
